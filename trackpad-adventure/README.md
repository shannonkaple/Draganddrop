# Ms. Kaple & Rigby's Tech Rescue

Students help pack scattered technology supplies in a Rainbow World. Five practice tasks introduce 23 hardware and screen vocabulary items by name and function with three drops each. Five independent missions use function clues and five requested items each. Rigby's final check requires ten drops. Each adventure requires 50 successful held-pointer drags, with three visible choices at a time. Bad guys appear from the third practice task onward; all eight appear in the first adventure. All dragging requires a held mouse pointer; touchscreen and click-only attempts do not pack items. A browser cannot detect the trackpad or the student's two-hand technique.

Each successful item drop immediately earns one Drag Star (50 per full adventure); shopping is available during missions and resumes the current task. A completed round includes a three-part star self-check, a choice of rescue friend and a required choice of home. Worlds cost 4, 6, 8, 10, 12 and 14 stars. Character appearances cost 3 then 5 stars. Until a first world is owned, upgrades reserve 4 stars for that world. Friends can move between owned worlds for free. Inside each world, held-pointer drags freely place friends and purchased decorations; percentage positions save by world and character. These free placement drags do not award stars. Decorations cost 2–6 stars. Items collected and each friend's home persist independently.

Existing number saves retain progress, stars, characters and purchased appearances. Legacy saves with friends retain their former selected world as an owned world. New players must buy worlds. Pending rescue/home choices survive reloads.

Ms. Kaple and Rigby are mission guides, not player or new rescue choices. They use the supplied transparent character artwork beside large white speech bubbles. Saved students using a guide as their hero choose a replacement player without losing stars or task progress. These images are optimized WebP assets with alpha preserved. Shared Arrow Adventure data is unchanged.

Student progress and CSV reports are browser-local. Students select their teacher, then their number. Saves use kaple-trackpad-adventure-v2:<stable teacher ID>:<number>; number 1 in two classes has separate progress. Original v1 number-only records remain untouched. The teacher panel can copy unassigned old records into empty slots for a selected class with code 8714; existing class saves are never overwritten. teachers.json contains 15 stable teacher IDs with temporary labels. Teacher names must be approved for publication before replacing those labels. No class codes or server synchronization are added.

The first 15 practice drops cover monitor, mouse, speakers, keyboard, printer, microphone, projector, headphones, taskbar, file, window, tab, close button, icon and cursor. The teacher-supplied Mouse & Trackpad Skills list appears as a separate read-aloud glossary; gameplay continues to require held-pointer dragging.

Rigby review regression: previously packed items may appear as distractors; every visible option remains draggable until the current task is complete. A correct release only packs the currently requested item.

Hazards use swept full-token collision against the visibly outlined obstacle bodies, including release events and moving hazards crossing a held stationary token. Missions 3 and 5 have slow patrols. Early practice hazards stay stationary. Floating confetti stars are removed; reward feedback is a short button highlight.


## Shop artwork and player changes
Twelve transparent decorations are extracted from Ms. Kaple’s supplied rainbow artwork. They cost 2–10 Drag Stars and can be dragged around owned worlds. Existing flowers/tree/tent/trophy purchase IDs are retained. Change character on the home or shop screen; stars, rescues, current tasks and individual player upgrades persist.
