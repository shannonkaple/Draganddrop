# Arrow adventure shop update

The existing number-based login, saves, maze generation, arrow controls, hazards, collections, level progression, upgrades and read-aloud controls are retained. Main adventure skill stops use arrow-key sequences.

Students can change to a rescued character without resetting progress. Finish mazes to earn Rainbow Stars; use Star Shop on the home, maze or My Stuff screens to buy worlds and decorations. Friends and decorations can be dragged around purchased worlds, with positions saved locally by student number. Existing homes are grandfathered into ownedWorldIds.

Twelve transparent WebP decorations were extracted from teacher-supplied sheets. Decoration IDs and prices are shared with the trackpad game, while wallets and progress remain separate. Existing endless practice is also retained.

Both games list Sims, Juvenal, and Rizzutto alongside the existing homerooms, with student numbers 1–24. Arrow saves now use rainbow-road-class-v3:<class ID>:<number>. The teacher panel (8714) can copy old number-only progress to its original class without replacing existing saves or deleting backups. Each old slot can be assigned once.
